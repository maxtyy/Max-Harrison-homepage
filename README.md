# Max Harrison

Personal website for Max Harrison, a postgraduate student in Financial Technology at The Hong Kong Polytechnic University.

## Background

- Research interests in quantitative trading and gambling risk management.
- Internship experience at HSBC.
- Working on QuantForge, a Python platform for quantitative research, backtesting, risk controls, and local paper trading.

## Website

Visit [Max Harrison's personal website](https://maxtyy.github.io/Max-Harrison-homepage/).

The site uses plain HTML and CSS and is published through GitHub Pages from the root of the `main` branch.

## Featured project

The [Projects section](https://maxtyy.github.io/Max-Harrison-homepage/#projects) features **QuantForge**, including its strategies, execution model, risk controls, paper accounts, and technology stack.

[QuantForge on GitHub](https://github.com/maxtyy/quantforge) is a private repository; source access requires authorization.
